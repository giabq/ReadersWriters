# Instruções de compilação

```
IMPORTANTE: o projeto foi feito em Java 23, então é
recomendado que essa versão seja utilizada na
compilação e execução
```

Para executar o projeto, rode o arquivo ```testeLeitoresEscritores```. Esse arquivo roda automaticamente todos os testes requisitados (ou seja, 50 testes para cada proporção de leitores/escritores de 0 a 100), primeiramente com um controlador que utiliza Readers e Writers e em seguida com um controlador que não utiliza esse mecanismo. Como saída, os testes exibem a proporção de leitores para escritores (onde 0% significa que não há qualquer leitor e 100% significa que não há qualquer escritor) e o tempo médio obtido por meio dos 50 testes.
